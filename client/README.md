# Smart B2B Logistics & Delivery Optimization Platform

An Enterprise-Grade Portfolio System built on the MERN stack (MongoDB, Express.js, React.js, Node.js). 

## Project Overview
This platform solves critical operational frictions in modern supply chains, including black-box visibility, poor asset utilization, and manifest corruption. It provides a unified closed-loop system for four distinct user roles:
- **Fleet Admin / Dispatcher** (Desktop)
- **Corporate Business Client** (Responsive Desktop)
- **Field Driver / Courier** (Mobile-First Touchscreen)
- **Executive / Strategy Lead** (Desktop Analytics)

## Tech Stack
- **Frontend:** React.js, Tailwind CSS, Redux Toolkit, Mapbox GL, Recharts
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas, Mongoose
- **Tooling:** Vite, Node-cron, Nodemailer

## Core Capabilities
1. **Unified Backend Engine:** One server serving role-based views.
2. **Real-Time Network Sync:** Status updates instantly reflect across all dashboards.
3. **Mobile Resilience:** Delta-time tracking ensures driver apps survive phone locks and backgrounding.
4. **Algorithmic Routing:** Auto-match cargo weight/volume to compatible vehicles.
5. **Executive Analytics:** Complex MongoDB aggregation pipelines.
